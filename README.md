## Instalación

Clona el repositorio:

```bash
git clone https://github.com/jhonas321/Portafolio.git
```

Entra al proyecto:

```bash
cd Portafolio
```

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto en modo desarrollo:

```bash
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
